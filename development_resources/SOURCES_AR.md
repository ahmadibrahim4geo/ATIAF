# سجل المصادر العلمية ومنصات تحميل المرئيات — أطياف
هذا سجل مختصر مرافق لـ[SOURCES.md](SOURCES.md) باللغة الإنجليزية، الذي يحتوي على الروابط والأدوار التفصيلية.

| المصدر | الوظيفة | الإتاحة |
|---|---|---|
| [USGS EarthExplorer](https://earthexplorer.usgs.gov/) | تحميل منتجات Landsat القديمة والحديثة | مجاني، بحساب مجاني للتنزيل |
| [NASA Earthdata Search](https://search.earthdata.nasa.gov/) | تحميل ASTER وMODIS وVIIRS وEMIT وECOSTRESS | مجاني، بحساب Earthdata |
| [Copernicus Browser](https://dataspace.copernicus.eu/browser/) | تحميل Sentinel-1 وSentinel-2 وSentinel-3 | مجاني، بحساب مجاني للتحميل |
| [EnMAP Portal](https://www.enmap.org/data_access/) | منتجات EnMAP فائقة الطيف | منتجات مجانية حسب شروط الوصول والتسجيل |
| [ASI PRISMA](https://www.asi.it/en/earth-science/prisma/) | منتجات PRISMA فائقة الطيف | تحميل وفق شروط التسجيل والترخيص |
| [ASF Vertex](https://search.asf.alaska.edu/) | بيانات SAR الرادارية | مجانية مع حساب Earthdata |
| [USGS C2 Guide](https://www.usgs.gov/landsat-missions/landsat-collection-2-level-2-science-products) | معاملات الانعكاسية والحرارة والجودة | توثيق رسمي |
| [ASTER Products](https://asterweb.jpl.nasa.gov/data_products.asp) | أنواع منتجات ASTER | توثيق رسمي |
| [Awesome Spectral Indices](https://github.com/awesome-spectral-indices/awesome-spectral-indices) | كتالوج المعادلات، مرشح للنسخة المحلية | ترخيص MIT مع مراجعة الإصدار |
| [Spyndex](https://github.com/awesome-spectral-indices/spyndex) | مرجع حسابي لمؤشرات Python | ترخيص MIT |
| [Index DataBase](https://www.indexdatabase.de/db/i.php) | مقارنة المؤشرات والمستشعرات | لا تُعاد توزيع قاعدة بيانات API كاملة وفق شروطها الحالية |

**قاعدة مهمة:** ذكر المصدر أو استخدامه للمراجعة لا يعني نسخه داخل الأداة. كل مكتبة أو بيانات تُدمج بعد فحص الترخيص وتثبيت الإصدار؛ تشغيل أدوات أطياف نفسه لا يتطلب إنترنت.

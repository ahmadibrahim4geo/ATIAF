The 6 Canonical Processing Tools | الأدوات الست الأساسية

Complete standalone geoprocessing pipelines in ArcGIS Pro (.pyt) and QGIS Processing.

🌿
01. Spectral Indices
المؤشرات الطيفية البصرية

22 validated optical spectral indices (NDVI, NDWI, MNDWI, NDMI, MSAVI, OSAVI, VARI, GLI, TCB, TCG, TCW, NDBI, NBR, SAVI, EVI, BSI) with automated QA cloud masking and true polygon boundary clipping.

Landsat 1-9 Sentinel-2 ASTER
Explore Indices in Catalog →
🌡️
02. Surface Temperature
درجة حرارة السطح والانبعاثية

Land Surface Temperature (LST in Kelvin / Celsius) and Land Surface Emissivity (LSE) calculated via Sobrino et al. (2004) NDVI thresholds model. Strictly enforces thermal sensor presence.

Landsat 4-9 C2 L2 ASTER AST_08 S2 Blocked (No Thermal)
Explore Thermal Models →
🏙️
03. Urban Heat Islands
الجزر الحرارية الحضرية

Urban Thermal Field Variance Index (UTFVI) with 6-class ecological comfort classification (Excellent to Worst), Severe Thermal Hotspots (z >= 2.0 sigma), and Surface Urban Heat Island (SUHI) mapping.

Landsat TIRS ASTER TIR Urban Climatology
Explore Urban Heat →
☀️
04. Environmental Drought
الجفاف البيئي والبيدو السطح

Liang (2001) broadband shortwave surface albedo (alpha) and Temperature Vegetation Dryness Index (TVDI) based on empirical LST-NDVI trapezoidal feature space for soil moisture monitoring.

Landsat 4-9 Sentinel-2 Energy Balance
Explore Drought Models →
💎
05. Geological Analysis
التحليل الجيولوجي والتعدين

8 diagnostic mineral alteration ratios (ferric/ferrous iron, gossan, hydroxyl/clay alteration, alunite, silica). Enforces ASTER post-April 2008 SWIR hardware failure safety cutoff.

ASTER VNIR/SWIR/TIR Landsat 4-9 Mineral Exploration
Explore Mineral Ratios →
🔥
06. Temporal Change
التحليل الزمني وحرائق الغابات

Multi-temporal difference products (dNDVI, dLST) and dNBR with official USGS FIREMON 7-class Burn Severity classification, relative percentage change, and standard deviation anomaly maps.

Landsat 4-9 Sentinel-2 USGS Burn Severity

Host Installation & Workflow Guides | دليل الإعداد والتشغيل

Step-by-step instructions for ArcGIS Pro, QGIS, and Python CLI automation.

1

Add ATIAF.pyt to ArcGIS Pro Catalog

Open ArcGIS Pro, locate the Catalog Pane, right-click Toolboxes → Add Toolbox, and navigate to arcgis_pro/ATIAF.pyt.

2

Select Unpacked Scene Folder

Open any of the 6 canonical tools. Select your unpacked satellite folder (e.g. LC08_L2SP_...). ATIAF automatically parses metadata files and verifies calibration.

3

Choose Projected Metre CRS (Decision D-007)

Pick your local projected coordinate system in linear metres (e.g. UTM). Unprojected geographic degrees (EPSG:4326) are strictly rejected to ensure physical accuracy.

4

Click Run & Inspect Results

GeoTIFFs are created in Results/, layered onto your active map, with complete bilingual HTML reports in Results/Reports/index.html.

1

Copy or Symlink qgis/atyaf

Link the qgis/atyaf folder into your active QGIS profile: %APPDATA%\QGIS\QGIS3\profiles\default\python\plugins\atyaf (Windows) or ~/.local/share/QGIS/QGIS3/... (Linux).

2

Enable ATIAF in Plugins Manager

In QGIS, go to Plugins -> Manage and Install Plugins, search for ATIAF (أطياف) under Installed, and enable it.

3

Access Processing Toolbox

Press Ctrl+Alt+T to open the Processing Toolbox. All 6 canonical algorithms are listed under the ATIAF | أطياف provider.

4

Execute with Native Parity

Double-click any algorithm, select your unpacked folder, configure options, and click Run. Output layers are added automatically to the QGIS canvas.

1

Run Diagnostics Suite

Verify that your scientific environment (NumPy, Rasterio, Shapely, PyProj) and ATIAF engines are healthy:

$ python tools/verify_installation.py
2

Pure-Python Automation API

Use atyaf_core in headless pipelines or Jupyter Notebooks without GIS GUI overhead:

>>> from atyaf_core.indices import SpectralIndicesEngine

The 6 Canonical Processing Tools | الأدوات الست الأساسية

Autonomous standalone geoprocessing tools integrated into ArcGIS Pro and QGIS.

01. Spectral Indices Tool 01
المؤشرات الطيفية البصرية

22 validated optical spectral indices (NDVI, NDWI, MNDWI, NDMI, MSAVI, OSAVI, VARI, GLI, TCB, TCG, TCW, NDBI, NBR, SAVI, EVI, BSI) with automated QA masking and polygon clipping.

Supported:Landsat 1-9, Sentinel-2, ASTER
02. Surface Temperature Tool 02
درجة حرارة السطح والانبعاثية

Land Surface Temperature (Kelvin / Celsius) and Emissivity via Sobrino et al. (2004) NDVI thresholds model. Strictly enforces thermal sensor presence.

Supported:Landsat 4-9, ASTER TIR
03. Urban Heat Islands Tool 03
التحليل الحراري والجزر الحرارية

Urban Thermal Field Variance Index (UTFVI; 6-class ecological comfort), Severe Thermal Hotspots (z >= 2.0), and Surface Urban Heat Island (SUHI) mapping.

Supported:Landsat 4-9, ASTER TIR
04. Environmental Drought Tool 04
التحليل البيئي ومؤشرات الجفاف

Liang (2001) broadband shortwave surface albedo and Temperature Vegetation Dryness Index (TVDI) based on empirical LST-NDVI trapezoidal feature space.

Supported:Landsat 4-9, Sentinel-2
05. Geological Analysis Tool 05
التحليل الجيولوجي ونطاقات التحول

8 diagnostic mineral alteration ratios (ferric/ferrous iron, gossan, hydroxyl/clay alteration, alunite, quartz). Enforces ASTER post-April 2008 SWIR hardware cutoff.

Supported:ASTER, Landsat 4-9
06. Temporal Change Tool 06
التحليل الزمني وتغير الغطاء الأرضي

dNDVI, dLST, and dNBR with official USGS FIREMON 7-class Burn Severity classification, relative percentage change, and standard deviation anomaly maps.

Supported:Landsat 4-9, Sentinel-2

Host Installation & Workflow Guides | دليل الإعداد والتشغيل

Step-by-step instructions for running ATIAF inside ArcGIS Pro, QGIS, or Python CLI.

Native ArcGIS Pro Integration (Toolbox `.pyt`)

Works natively in ArcGIS Pro 3.0+ without compilation or third-party add-ins.

1

Add Toolbox to Catalog

In ArcGIS Pro, open the Catalog Pane, right-click Toolboxes -> Add Toolbox, and navigate to arcgis_pro/ATIAF.pyt.

2

Select Satellite Imagery Folder

Open any tool (e.g., 01. Spectral Indices). Point the Imagery Input Folder parameter to your unpacked scene directory (e.g. Landsat or Sentinel-2 folder).

3

Choose Projected Metre CRS & AOI

Select your desired output projected coordinate system (in metres, such as UTM). Optionally select a study area polygon to clip outputs automatically.

4

Click Run & View Results

Outputs are generated in Results/, layered directly onto your active map, with complete HTML run reports in Results/Reports/index.html.

Native QGIS Processing Provider (`qgis/atyaf`)

Full compliance with QGIS Processing Framework in QGIS 3.x and 4.x.

1

Install or Link Plugin Folder

Copy or link qgis/atyaf to your active QGIS profile plugin folder (e.g., %APPDATA%\QGIS\QGIS3\profiles\default\python\plugins\atyaf).

2

Enable in Plugins Manager

In QGIS, go to Plugins -> Manage and Install Plugins, locate ATIAF (أطياف) under Installed, and enable its checkbox.

3

Open Processing Toolbox

Open the Processing Toolbox (Ctrl+Alt+T) to find the ATIAF | أطياف provider containing all 6 algorithms.

4

Execute & Inspect Results

Double-click any algorithm, pick your scene folder, set options, and click Run. Output rasters are instantly added to your QGIS layer canvas.

Command-Line Diagnostics & Batch Processing

Run automated environment verifications and batch pipelines programmatically.

1

Run Diagnostics Tool

Verify all NumPy, Rasterio, Shapely, PyProj, and engine dependencies in one command:

$ python tools/verify_installation.py
2

Batch Scripting with atyaf_core

Import pure-Python engines directly in Python scripts or Jupyter Notebooks without GIS GUI overhead:

>>> from atyaf_core.indices import SpectralIndicesEngine

# حل المشكلات في أطياف
| الحالة | السلوك المطلوب |
|---|---|
| ملف Metadata غير موجود | عرض وضع ربط باندات يدوي متقدم؛ عدم اختلاق معاملات المعايرة |
| اختيار مستشعر خاطئ | تنبيه يوضح التناقض وإيقاف الحسابات غير الآمنة |
| محاولة LST من Sentinel-2 فقط | تعطيل الحساب لعدم وجود نطاقات حرارية |
| غياب SWIR | تعطيل المؤشرات المعتمدة عليه مع ذكر النطاق المطلوب |
| مسقط جغرافي بالدرجات أو غير معروف | استخدام منتقي الإسقاط الأصلي لاختيار مسقط متري؛ تعريف النظام الأصلي أولًا إذا كان مجهولًا |
| المرئية لا تتقاطع مع منطقة القص | تنبيه بعدم وجود بكسلات صالحة بدل إنتاج ملف خاطئ |
| موزاييك لمشاهد بتواريخ مختلفة | تنبيه واختبار القابلية للمقارنة وتسجيل التاريخ ومصدر المشاهد |
| نتيجة بنفس الاسم موجودة | إعادة استعمالها فقط عند إثبات تطابق المدخلات والمعاملات؛ وإلا نسخة مميزة دون حذف القديم |
| فشل إضافة طبقة للخريطة | حفظ النتيجة والاستمرار وتسجيل فشل العرض منفصلًا عن الحساب |
| فشل بسبب الذاكرة أو انقطاع | تسجيل الخطوة التي تمت والقدرة على الاستئناف دون تلف النتائج السابقة |

كل مشكلة لها رسالة عربية صحيحة، وترجمة إنجليزية، ورمز خطأ ثابت، وتفاصيل دقيقة في `Processing_Log.txt` وملف التقرير العلمي. لا تُسجل كلمات مرور أو توكنات أو بيانات خاصة في التقارير العامة.

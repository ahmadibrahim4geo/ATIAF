# قواعد واجهة كل أداة ومسار الحفظ
كل أداة تُظهر الأقسام نفسها بالترتيب: **القمر والمستشعر ← مجلد المرئيات ← إعدادات المعالجة ← الموزاييك الاختياري ← حسابات الأداة ← منطقة الدراسة والمسقط ← الحفظ في آخر الواجهة**. يوجد خيار إضافة النتائج إلى الخريطة بالتتابع قرب الحفظ.

المؤشرات في مجموعات موضوعية، كل مؤشر له مربع اختيار مستقل، افتراضيًا غير محدد، ولا يظهر غير المتوافق كمسموح؛ يظهر معطلًا مع السبب. فحص المستشعر لا يعتمد على اسم مجلد المرئية فقط؛ يراجع ملفات الباندات والمعلومات والتواريخ والمستوى. الوضع اليدوي المتقدم يطلب تحديد كل باند ودوره ومعاملات المعالجة الصحيحة، ويرفض فرضيات التخمين.

**المسقط:** استخدم منتقي الإسقاطات الأصلي في ArcGIS Pro أو QGIS؛ لا نضع UTM 36 أو أي EPSG افتراضي لجميع بلدان العالم، ونحتفظ بالمسقط المترى الملائم للمدخل ما أمكن. **الحفظ:** مسار الإدخال افتراضيًا؛ إذا اختار المستخدم مسارًا مختلفًا لا تغيره الأداة بعد ذلك تلقائيًا. عند التكرار تضاف مجلدات الحسابات إلى `Results` الموجود دون حذف.

**الواجهة الأصلية:** Python Toolbox في ArcGIS Pro قد لا تسمح بجدول Checkbox معقد بالتصميم المتخيل؛ يجب اختبار قدرات معاملات ArcPy الفعلية، واستخدام معاملات مدعومة أو إضافة واجهة اختيارية عند الحاجة، دون التضحية بصحة الحسابات أو وعد المستخدم بشيء غير منفذ.

# Installation and project startup — documentation handoff
This ZIP contains **plans, registries, governance rules, and helper scripts**; there is no runnable ArcGIS Pro or QGIS toolbox yet. Extract the ZIP so the root folder is exactly `أطياف/`. Open `START_AGENT_PROMPT.txt`, copy its text to your coding agent and read `AGENTS.md`. Check package structure: `python tools/validate_package.py`. On an internet-connected development machine run `python tools/bootstrap_skills.py` to clone the approved source skills, then inspect its license/commit and actual SKILL.md references. The agent implements `.pyt` and QGIS tools according to the roadmap and records test evidence. Do not attempt to install a non-existent plugin or claim a calculation succeeded.

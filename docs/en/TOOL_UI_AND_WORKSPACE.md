# Tool user interface and independent processing contract
Each ATIAF tool is a separate native GIS geoprocessing operation with **common sections** implemented using a shared config schema and host adapter. Order: satellite/instrument -> imagery folder -> preprocessing -> mosaic -> tool-specific methods -> AOI and host CRS -> **output folder last**, and the optional `Add Results to Map` checkbox next to output settings.

- Native ArcGIS Pro `.pyt`: use `getParameterInfo`/`updateParameters`/`updateMessages`/`execute` and host-sanctioned data types, dropdowns and CRS chooser. Native geoprocessing UI does NOT inherently offer a fully arbitrary 2D hierarchical checkbox table; validate capability and consider ValueTable, multi-value methods or optional C# dockpane when native widgets cannot meet UX acceptance. Do not claim custom controls exist without a real ArcGIS Pro host test.
- QGIS: `QgsProcessingAlgorithm` or Processing provider and native `QgsProcessingParameterCrs`; use compatible QGIS widgets. Native UI may differ, but semantics and algorithms must match.
- Real-time user input validation: file paths and product-level consistency, detected satellite vs manual choice, actual band asset availability, QA/cloud, projected metre CRS, memory/disk sufficiency, AOI overlap, output folder permissions, supported method.
- Themed checkbox catalog: categories Vegetation/Pigments, Water, Soil/Agriculture, Urban, Burn/Snow, Geological/Mineral, Thermal/Drought, Advanced Transforms. Each row has unique scientific ID/acronym, Arabic or English display name, required bands and reason unavailable. None checked by default. Group select/clear and search where native host UI supports them.
- Changing sensor does not silently keep incompatible selected indices. An unavailable checkbox should be visible but disabled and explain reason for missing red-edge/SWIR/TIR/ancillary/historical products.
- Processing policy: single scene or parent folder, mosaic off by default; custom folder last parameter, inherits source on first setting, manual change never overwritten by other parameter events.
- Native output map option unchecked or user-configured; sequential, event-safe layer addition, timeouts/host responsiveness; no fixed blocking `sleep` on GUI thread; failed render separate from valid raster output.
- Help tooltip/localization parity, source/uncertainty disclaimers, and structured logs must be in both languages.

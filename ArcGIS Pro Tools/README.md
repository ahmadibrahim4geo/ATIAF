# ATIAF for ArcGIS Pro

English: `ATIAF.pyt`. العربية: `ATIAF_AR.pyt`.

Keep this folder beside `atiaf_core`. `atiaf_arcgis.py` is the thin native adapter, not another engine. Sensor is first; explicit calculations follow QA/mosaic; output folder is LAST. Missing science dependencies cannot empty the controls. Refresh/reopen old dialogs after updates.

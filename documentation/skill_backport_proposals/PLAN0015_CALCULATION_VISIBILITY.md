# Reusable guidance proposal from PLAN-0015

Proposal only; upstream GIS-Development-Skills was not edited.

1. Native tool catalogs should load independently of optional numerical dependencies. Test dependency absence and require a useful error without erasing calculation choices.
2. Validate the actual parameter list/defaults in each host, then execute representative calculations and independently reopen products. Class declarations, syntax and one imported provider do not establish six usable tools.
3. A rename facade must not load duplicate nested Python modules/classes. Prefer one canonical implementation and a documented migration; if an alias is retained, verify nested module/type identity.
4. Treat diagnostics as narrowly scoped observations: imported formula definitions are not scientifically validated formulas; a built ZIP is not a clean-machine installation.
5. Explicitly document host control limits. A disabled ArcGIS parameter may be hidden; a standard QGIS enum cannot independently grey incompatible rows. UI acceptance must observe the actual control, not only a mocked property.
6. A requested screenshot size may differ from the browser's layout viewport. Record actual dimensions, test image decoding/overflow and inspect screenshots. Test-proof elements must not alter layout.

Evidence: tests and report 0016 in ATIAF. No third-party implementation copied.

# نموذج تقرير عملية علمية — مثال فقط
- معرف التشغيل: `RUN-...`
- اسم العملية والاسم العلمي والاختصار والمعرف الداخلي:
- مرئية الإدخال: معرف المشهد والتاريخ والقمر والمستشعر ومستوى المعالجة:
- الباندات: **الملف الحقيقي**، رقم الباند، دوره، الطول الموجي، الدقة، الوحدة، وMetadata:
- المعادلة: والتعريفات والثوابت والمتغيرات:
- معاملات القياس: القيمة، الوحدة، **المصدر الدقيق**: Metadata filename:key / Scientific DOI/URL / User input:
- المعالجة الأولية: كل ما نُفذ وما لم يُنفذ والسبب:
- أقنعة الجودة وNoData والبكسلات المستبعدة:
- المسقط والدقة وعمليات التحويل وإعادة أخذ العينات:
- الموزاييك والقص والمصدر لكل مشهد وتاريخه:
- ملفات النتائج ووحداتها ونوع الراستر:
- نتائج اختبار سلامة الملفات وملخص جودة النتائج:
- الأخطاء والتحذيرات والمحدوديات والمراجع:

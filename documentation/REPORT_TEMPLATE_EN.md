# Scientific Processing Report — example-only template
Run ID, tool/method ID, scientific name/acronym, scene ID/date/platform/instrument/processing level, exact input file mapping and wavelength/role, formula/constants/units, per-value provenance (scene metadata filename:key vs scholarly DOI/reference vs user input), all preprocessing applied/skipped and why, QA/NoData/uncertainty, source/target CRS and reproject/resample grid, mosaic/AOI, exact output paths/data types/units, readback QA metrics, warnings/errors/limitations, and citations. This template will be used to generate real per-run reports when implementation and tests exist.

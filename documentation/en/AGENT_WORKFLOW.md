**The authoritative contract is [`AGENTS.md`](../../AGENTS.md) in the root.** Begin each session by checking project root, AGENTS, state, specifications, plan index/active plans, report index/latest report, canonical development journal and actual git/code/test state. Bootstrap/read approved GIS skills if possible; do not claim installation without observed success. Intake `PLAN_*.md` files to uniquely numbered Active plans. Execute with scientific tests, write unique `Reports/000N_...md`, update indexes/state/journal; archive into Completed only after verified acceptance. Otherwise record blockers and handoff. Previous work and files are never silently erased.

Troubleshooting

SymptomAction
Old order / absent controlsClose tool, Refresh toolbox/restart Pro. Open this complete checkout, not an old isolated copy.
Missing scientific libraryControls remain visible. Check the exact active host Python using the read-only helper, repair a compatible cloned environment and restart.
Empty selectionCheck a calculation; open the multi-select list in QGIS.
Sensor mismatch / missing bandsChoose AUTO or correct metadata level; supply complete assets or reviewed expert mapping.
Missing QARestore actual mask or explicitly disable QA after assessing limitations.
Invalid CRSUse native projected metre picker. Correctly define unknown source CRS first.
TVDI / SUHI / historical models gatedRequired dry/wet edges, urban/rural references or historical baseline are not implemented as validated inputs yet.
AOI errorSupply valid nonempty polygon with known CRS.
Raster saved / no map layerOpen it manually; inspect native map warnings. Saved outputs remain independent of rendering.

Record tool, selected methods, product level, host/environment and exact error. Do not upload imagery or private paths without consent. Current evidence.

سياسة أسماء المخرجات والتقارير العلمية

تستخدم كل أدوات أطياف Results الموجود وتضيف مجلداتها دون مسح الملفات. لكل مؤشر مجلد واضح، وتوجد نتيجة كاملة FULL ونتيجة قص CLIP داخل مجلد المؤشر. يظل Work للملفات المؤقتة والكاش الذي يعاد استعماله بعد التحقق فقط.

مثال: Results/Spectral_Indices/Vegetation/NDVI/NDVI_<SCENEID>_FULL.tif، وResults/Surface_Temperature/LST/LST_<SCENEID>_Celsius.tif.

المعلومات التي يجب أن يعرفها الباحث

- الاسم الكامل للمرئية ومعرفها والمستشعر وتاريخ التصوير ومستوى المعالجة.

- اسم كل باند استعمل فعلًا، مثل SR_B4 لدور Red وSR_B5 لدور NIR في Landsat 8؛ ومسار الملف وبُعده الموجي والدقة والوحدة.

- المعادلة الحقيقية وأي صيغة بديلة وأسماء الثوابت والقيم.

- عند قراءة قيمة من ملف معلومات المرئية: اسم ملف Metadata + المفتاح الأصلي + القيمة + الوحدة، مثل معامل إعادة التحجيم؛ وإذا كانت القيمة مرجعية من USGS أو بحث علمي يُذكر الرابط، وإذا اختارها المستخدم يُقال ذلك صراحة.

- أي تصحيح أو قناع سحب أو ظل أو حذف NoData، وهل نُفذ أم تُخطي ولماذا.

- المسقط الأصلي والنهائي وتحويلات الإحداثيات والدقة النهائية والطبيعية للمستشعر.

- بيانات الموزاييك ومن أي مشهد جاءت النتائج، ومنطقة القص إن وجدت، وملاحظات المقارنة بين التواريخ.

- نتائج فحص البكسلات الصالحة والجودة وعدم اليقين والتحذيرات والأخطاء.

ملفات تقرير كل تشغيل

Processing_Report.html للقراءة، وProcessing_Manifest.json لسجل البيانات، وBand_Mapping.csv للباندات، وQuality_Assessment.csv للجودة، وProcessing_Log.txt للأخطاء، وResults/Reports/index.html فهرس يتجدد دون حذف التقارير القديمة. لا تُنشر مسارات شخصية أو مفاتيح سرية على GitHub.

إضافات التقارير الحالية

تتضمن تقارير الحسابات باللغتين المعنى والوحدات والمدى ومحاذير التفسير. التشغيل اليدوي يصدر Manual_Band_Mapping.json لإعادة الاستخدام. تصنيف NDVI الاختياري ينتج راستر LOCAL_CLASSES منفصلًا ومفتاح فئات JSON باللغتين وسجل تشغيل يسجل الحدود الأصلية والفعلية والأساس المحلي؛ تبقى قيم المؤشر المستمر كما هي. اشتقاق الحرارة يسجل مسارات الإشعاع وNDVI ومدخلات الغلاف الجوي والانبعاثية والمعادلة والافتراضات. اختبارات البيانات الصناعية والمضيف الأصلي لا تثبت الدقة الميدانية.

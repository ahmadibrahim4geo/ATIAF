# استكشاف الأخطاء

| العرض | التصرف |
|---|---|
| ترتيب قديم أو غياب الحسابات | أغلق الأداة ونفّذ Refresh أو أعد تشغيل Pro. افتح المستودع الكامل الحالي وليس نسخة قديمة منفصلة. |
| مكتبة علمية ناقصة | الحسابات تظل ظاهرة. افحص بيئة Python النشطة للمضيف بملف الفحص فقط، وأصلح بيئة مستنسخة متوافقة ثم أعد التشغيل. |
| لا حساب محدد | حدّد مربعًا؛ في QGIS افتح قائمة الاختيار المتعدد. |
| تعارض مستشعر أو باند ناقص | اختر AUTO أو مستوى الميتاداتا الصحيح، وأكمل الأصول أو عيّنها بوضع الخبير الموثق. |
| جودة ناقصة | أعد القناع الأصلي أو ألغِ الجودة صراحةً بعد تقييم حدود النتيجة. |
| مسقط غير صالح | اختر مسقطًا بالمتر من المنتقي الأصلي. المصدر المجهول يحتاج تعريفًا صحيحًا أولًا. |
| حسابات TVDI أو SUHI أو التاريخ موقوفة | مدخلات حدود الجفاف والرطوبة أو المرجع الحضري والريفي أو المرجع التاريخي لم تُنفذ بصورة موثقة بعد. |
| خطأ المضلع | مصدر صالح غير فارغ ومسقطه معروف. |
| الراستر محفوظ دون طبقة | افتحه يدويًا وافحص تحذيرات الخريطة؛ الملف مستقل عن تعطل العرض. |

سجّل الأداة والحسابات والمستوى وإصدار المضيف والبيئة ونص الخطأ، دون رفع الصور أو مسارات خاصة دون إذن. [الحالة الفعلية](../../PROJECT_STATE.md).

# تعيين الباندات يدويًا للخبير

هذا تعريف JSON قديم واختياري عند معرفة المستشعر والتاريخ والباندات ومعايرتها ومستوى المنتج. في الواجهة الحالية اختر المستشعر الفعلي وفعّل التعيين اليدوي، ثم استورد الملف اختياريًا؛ [حقول الباندات الأصلية](MANUAL_BANDS.md) لا تحتاج JSON. المسار البرمجي القديم sensor=EXPERT ما زال يقبل هذا التعريف بمسارات داخل المشهد. التشغيل اليدوي المباشر يصدر تعريف atiaf_manual_v1 الأحدث داخل تقريره الفريد. لا يحدث تنزيل أثناء المعالجة.

```json
{
  "scene_id": "MY_SCENE",
  "platform": "Landsat 8",
  "instrument": "OLI_TIRS",
  "sensor_family": "Landsat",
  "product_level": "L2_SR",
  "acquisition_date": "2023-05-20",
  "bands": {
    "red": {"file": "red.tif", "scale": 0.0000275, "offset": -0.2, "unit": "reflectance", "wavelength_nm": 655, "provenance": "دليل USGS C2 L2 مع التحقق أن الملف أرقام SR الخام"},
    "nir": {"file": "nir.tif", "scale": 0.0000275, "offset": -0.2, "unit": "reflectance", "wavelength_nm": 865, "provenance": "دليل USGS C2 L2 مع التحقق أن الملف أرقام SR الخام"}
  }
}
```

القيم مثال لمنتج Landsat C2 L2 SR غير المحوّل، وليست ثوابت لكل الصور. الانعكاسية المحوّلة بالفعل تستخدم معامل 1 وإزاحة 0 مع إثبات المصدر. لكل باند معامل وإزاحة وطول موجي ومصدر معايرة صريح. المسقط المجهول والباند الناقص والمستوى غير المدعوم تمنع التنفيذ. صيغة التعيين الحالية لا تتضمن تعيين أقنعة الجودة؛ إبقاء تطبيق الجودة مفعّلًا يمنع التشغيل دون القناع، ويمكن للخبير إلغاؤه صراحةً بعد تقييم السحب والإشباع. لا تُوصف النتيجة حينئذ بأنها موثقة الجودة. لا يحوّل هذا الوضع أرقام الحرارة العشوائية أو حرارة السطوع إلى حرارة سطح. تعيين ملفين خبيرين للمقارنة الزمنية غير متاح حاليًا.

# المعاملات وحفظ النتائج

المستشعر أولًا والحفظ آخر إعداد. مجلد بيانات الإدخال يقبل مشهدًا أو مجلدًا يضم مشاهد. خيار التعيين اليدوي بعد الإدخال يُظهر حقول الملفات والمعايرة المحلية؛ استيراد JSON اختياري. تليه الجودة والدمج والمجموعات الموضوعية للحسابات والإعدادات الخاصة بالأداة ثم المضلع والمسقط الأصلي بالمتر والإضافة الاختيارية للخريطة والحفظ. الحسابات مربعات مسماة غير محددة افتراضيًا في البرنامجين دون بحث؛ QGIS بمجموعات أصلية وحقول شرطية، وPro بفئات معاملات وتفعيل شرطي أصلي.

المعايرة مرة واحدة. تُستخدم QA_PIXEL أو SCL وأعلام الإشباع المتاحة. تتوافق الباندات مع شبكة أول باند مطلوب بأقرب جار، ثم يطبق المسقط المطلوب بالمتر على الناتج. القاعدة مسجلة ولا تعني مواءمة بين المستشعرات. المسقط المجهول أو التحويل غير المتاح يوقف التشغيل ولا تُنزّل شبكات تلقائيًا.

الوجهة الافتراضية أو المطابقة للإدخال تستخدم `Work/Preprocessing_Cache/` و`Results/` لكل مرئية. الوجهة المخصصة تنشئ مجلدًا باسم المرئية داخلها. الأدوات تشترك في الحاويات ولكل ملف لاحقة تشغيل مميزة. التشغيل المتكرر يعيد الحساب بدل ادعاء كاش غير متحقق منه. قد تبقى منتجات الحرارة الوسيطة اللازمة. لا Results_2. التقارير تتراكم داخل `Results/Reports/Runs/` وفهرسها `Results/Reports/index.html`.

الدمج لمشاهد متوافقة في اليوم نفسه مع إبقاء نتائجها ومصدر كل مشهد. الزمن لمرئية لكل تاريخ ومستشعر ومستوى متطابقين وتاريخين مرتبين؛ الفرق الثاني ناقص الأول. الكامل والمقصوص ملفان مستقلان والمضلع غير الصالح خطأ صريح.

الكتابة المقطعية للراستر المستمر تستخدم ملفًا مؤقتًا خاصًا. بعض كتابات المشتقات وفهرس التقارير ما زالت تحتاج تحققًا أقوى للانقطاع والتزامن؛ لا ادعاء بتعافٍ معاملاتي كامل. قبول العرض على الخريطة منفصل عن إعادة فتح المنتج المحفوظ.

تُحفظ المؤشرات تحت Results/Spectral_Indices ثم المجموعة ثم المؤشر؛ الكامل والمقصوص داخل مجلد المؤشر نفسه.

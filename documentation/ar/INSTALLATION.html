التثبيت

نسخة تطوير 1.0.2.dev1. راجع حالة المشروع للإصدارات المشاهدة والاختبارات الناقصة. نجاح الاستيراد ليس قبول إصدار كامل.

ArcGIS Pro

احتفظ بمجلد ArcGIS Pro Tools/ بجوار atiaf_core/. أضف اتصال مجلد المشروع كاملًا في Catalog ثم افتح ATIAF_AR.pyt للعربية أو ATIAF.pyt للإنجليزية. أغلق نافذة الأداة القديمة ونفّذ Refresh أو أعد فتح Pro بعد التحديث؛ النافذة المفتوحة قد تحتفظ بمعاملات سابقة. لا تنقل .pyt وحده بعيدًا عن atiaf_arcgis.py والمحرك.

الاعتماديات: NumPy وRasterio وShapely وpyproj داخل بيئة Python النشطة في Pro. استنسخ البيئة المُدارة قبل تغيير الحزم واستخدم حزمًا متوافقة مع GDAL وPROJ في المضيف. ملفات التجهيز أصبحت فحصًا للقراءة فقط وليست تثبيت pip تلقائيًا:

"<ArcGIS Pro install>/bin/Python/scripts/propy.bat" tools/setup_arcgis_pro_env.py

نقص اعتماد يظهر رسالة واضحة وتبقى الحسابات ظاهرة. أصلح البيئة المستنسخة المتوافقة بمدير بيئات Pro ثم أعد التشغيل والفحص. ATIAF لا يغير تثبيتك الأساسي.

QGIS

نفّذ python tools/build_qgis_plugin.py. ثبّت QGIS Tools/Distribution/ATIAF-QGIS-1.0.2.dev1.zip من الإضافات ← إدارة وتثبيت الإضافات ← التثبيت من ZIP. فعّل ATIAF فتظهر أدواتها الست في Processing Toolbox. تتضمن الحزمة المحرك الأصلي MIT وتعريفات JSON، ولا تتضمن مرئيات أو كود أطراف أخرى. الاعتماديات يجب أن تتوافر في Python الخاصة بـQGIS؛ لا تخلط البيئات.

لغة الأدوات تتبع لغة QGIS. اختر المربعات تحت المجموعات الموضوعية؛ التعيين اليدوي يُظهر حقول الباندات المحلية. الاختيار غير المتوافق يُرفض مع بيان السبب وأزيل البحث. المعاملات الجديدة تتطلب مراجعة النماذج المحفوظة؛ معامل INDICES القديم مخفي للتوافق البرمجي. أعد تحميل الإضافة وافتح نافذة جديدة بعد التحديث.

الصيانة

tools/validate_package.py للملفات وJSON والروابط، وtools/verify_installation.py للاستيراد والصياغة وليس التحقق الأصلي أو المرئيات الحقيقية. tools/bootstrap_skills.py لمهارات التطوير وليس اعتماد مستخدم. البداية.

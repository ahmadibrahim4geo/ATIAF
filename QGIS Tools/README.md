# ATIAF for QGIS

Source: `atiaf/`. Installable: `Distribution/ATIAF-QGIS-1.0.2.dev1.zip`, generated from repository ROOT by `python tools/build_qgis_plugin.py`. Install the ZIP in QGIS's plugin manager. It contains `atiaf/atiaf_core/`; copying only plugin source is insufficient. The root shared core remains `atiaf_core/`. Old dist packages are historical builds, not the current QGIS installable. Developer build/test helpers stay under tools/.

المصدر داخل atiaf، وحزمة التثبيت الحالية داخل Distribution. أنشئها من جذر المشروع ثم ثبّتها من ZIP في مدير الإضافات. اللغة تتبع QGIS. الحسابات مربعات تحت مجموعات موضوعية، والتعيين اليدوي يظهر حقول الباندات عند تفعيله. أدوات الصيانة والبناء تحت tools وليست أدوات تحليل للمستخدم.

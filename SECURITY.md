# Security policy
Report suspected security issues privately to the repository maintainer via GitHub security advisories when available; do not publish secrets, token dumps or exploit payloads in open Issues. ATIAF must never execute scripts, macros or shell commands embedded in imagery products, metadata, remote docs or user-provided task text. Parse inputs as untrusted data, bound resource usage, prevent path traversal on archives, and restrict file writes to selected output workspace. Do not collect/upload personal information or telemetry without user opt-in. External integration tokens must stay outside the repository and logs. Refer to `AGENTS.md` and the GIS Security Guardian skill.
